> [!formula] Формулы рецептуры

## 2. Фармакокинетика — самое нужное

**Путь ЛВ:** всасывание → распределение → биотрансформация → выведение; **элиминация** = биотрансформация + экскреция.

**Пути введения:**
- в/в → **F = 100%**, эффект сразу;
- внутрь → **первое прохождение** (кишка + печень через воротную вену) → F ↓;
- под язык → **минует печень** (нитроглицерин);
- в/м и п/к → **при шоке всасывание ↓** → только в/в.

**Транспорт через мембраны:**
- **пассивная диффузия** — липофильные неионизированные (зависит от **pH** и **pKa**);
- фильтрация — мелкие гидрофильные;
- облегчённая диффузия — переносчик, по градиенту;
- **активный** — переносчик, **против градиента, АТФ**;
- пиноцитоз — крупные молекулы.

**Распределение:**
- действует **свободная** фракция; связанная с белками — депо;
- **Vd** малый → ЛВ в сосудах; большой → в тканях (диализ неэффективен).

**Биотрансформация:**

| Фаза I | Фаза II |
|---|---|
| **CYP450**: окисление, восстановление, гидролиз | **конъюгация**: глюкуроновая кислота (главная), сульфат, ацетил, метил, глутатион |
| метаболит неактивный, активный или токсичный | обычно неактивный, водорастворимый |

- **Индукторы** (рифампицин, фенобарбитал) → эффект других ЛС ↓.
- **Ингибиторы** (кларитромицин, флуконазол, грейпфрут) → токсичность ↑.

**Выведение:**
- Css и полное выведение — через **4–5 t½**;
- **недостаточность почек / печени** → Cl ↓ → t½ ↑ → кумуляция → **поддерживающую дозу ↓ или интервал ↑**.

> [!formula] Формулы фармакокинетики
> **F = AUC (внутрь) / AUC (в/в) × 100%**
> **Vd = D / C₀**
> **t½ = 0,693 · Vd / Cl**    **Cl = kel · Vd**
> **D нас = Css · Vd / F**    **D подд = Css · Cl · τ / F**
> Кислота: **lg (ион / неион) = pH − pKa** · основание: **pKa − pH**
> **ТИ = ТД₅₀ / ЭД₅₀**

## 3. Фармакодинамика — самое нужное

**Агонисты и антагонисты:**

| Лиганд | Внутренняя активность | Пример |
|---|---|---|
| Полный агонист | 1 | морфин, адреналин |
| Частичный агонист | 0–1 → на фоне полного = антагонист | бупренорфин |
| Антагонист | 0 | атропин, налоксон |
| Агонист-антагонист | разная на подтипах | буторфанол |

- **Конкурентный** антагонист → кривая **вправо**, max прежний.
- **Неконкурентный** → **max ↓**.

**Рецепторы — по скорости:**

| Тип | Скорость | Пример |
|---|---|---|
| Ионотропные | мс | N-холино-, ГАМК-A |
| G-белок (Gs / Gi / Gq) | с | адрено-, М-холино-, опиоидные |
| Тирозинкиназные | мин–ч | инсулин |
| Внутриклеточные | ч–дни | глюкокортикоиды, гормоны щитовидной железы |

**Виды действия** (пары): местное / резорбтивное · прямое / рефлекторное · главное / побочное · обратимое / необратимое · избирательное / неизбирательное.

**Виды фармакотерапии:** этиотропная (причина) · патогенетическая (механизм) · симптоматическая (симптом) · заместительная (дефицит) · профилактическая.

**Дозы:** пороговая → терапевтическая (высшая разовая / суточная) → насыщающая, поддерживающая → токсическая → летальная; **ТИ = ТД₅₀ / ЭД₅₀**.

**Повторное введение:**
- **кумуляция** — материальная (вещество) / функциональная (эффект);
- **толерантность** — десенситизация, down-регуляция, индукция ферментов;
- **тахифилаксия** — эфедрин;
- **зависимость** — психическая / физическая (абстиненция);
- **сенсибилизация** → аллергия.

**Взаимодействие:**
- **фармацевтическое** — вне организма (осадок);
- **ФК** — хелаты, вытеснение из связи с белками, индукция / ингибирование CYP, выведение;
- **ФД** — синергизм (суммирование, потенцирование), антагонизм (прямой, косвенный, химический);
- комбинированная терапия (обоснованно) vs **полипрагмазия** (необоснованно).

**Факторы:** возраст (новорождённые, пожилые) · пол, беременность · патология почек, печени, ХСН, шок · генетика (ацетиляторы, Г6ФД, псевдохолинэстераза) · идиосинкразия.

**Побочные реакции:**
- фармакодинамические (в терапевтических дозах);
- токсические (передозировка);
- вторичные (дисбактериоз, кандидоз, иммуносупрессия);
- аллергические (не зависят от дозы) и псевдоаллергические (без антител);
- на плод: эмбриотоксическое (0–2 нед.) → **тератогенное (3–8 нед.)** → фетотоксическое (с 9 нед.).

## 5. Тренировка к итоговому

> [!question]- Сколько капель 1% спиртового раствора нитроглицерина содержат 0,0005 г?
> 0,0005 г в 0,05 мл; спирт — 40 капель на 1 г (≈ 1 мл) → **2 капли**.

> [!question]- Какая доля слабой кислоты (pKa 4) не ионизирована в желудке при pH 2?
> pH − pKa = −2 → ион : неион = 1 : 100 → неионизировано ≈ **99%** — хорошо всасывается в желудке.

> [!question]- Выпишите 200 мл раствора так, чтобы в 1 чайной ложке было 0,1 г вещества.
> 1 ч. л. = 5 мл → 0,1 / 5 × 100% = **2%**. Rp.: Solutionis X 2% — 200 ml / D.S. По 1 чайной ложке … раз в день.

> [!question]- Выпишите 10 флаконов сухого вещества по 1,0 для в/м введения.
> Rp.: X 1,0 / D.t.d. N. 10 / S. Содержимое флакона растворить в … Вводить внутримышечно … (после D.t.d. N. ничего не пишут).

> [!question]- Препарат с t½ = 6 ч назначен постоянно. Когда будет Css и как ускорить?
> Через 4–5 t½ = 24–30 ч; ускорить — насыщающей дозой, затем поддерживающие.

> [!question]- Почему при шоке препараты вводят в/в, а не в/м?
> При шоке кровоток в мышцах снижен — всасывание плохое и непредсказуемое; в/в — F = 100%, эффект сразу, доза управляема.

> [!question]- Частичный агонист на фоне полного — что будет с эффектом?
> Уменьшится: частичный агонист занимает рецепторы и даёт меньший эффект — работает как антагонист.

> [!question]- Через какие посредники работают Gs, Gi, Gq?
> Gs — аденилатциклаза ↑ → цАМФ ↑; Gi — цАМФ ↓; Gq — фосфолипаза C → ИФ₃ (Ca²⁺ ↑) + ДАГ.

> [!question]- Назовите по одному примеру фармацевтического, фармакокинетического и фармакодинамического взаимодействия.
> Фармацевтическое — осадок кальция с гидрокарбонатом в одной системе. ФК — рифампицин снижает эффект оральных контрацептивов (индукция CYP). ФД — налоксон устраняет действие морфина.
