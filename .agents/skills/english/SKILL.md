# english

Аргументы: `[lesson | review | status — по умолчанию lesson]`.

Пути указаны от корня репозитория сайта. Прочитай AGENTS.md. Данные кафедры и внешние источники проверяй по прочитанным фрагментам. Общий порядок согласования и публикации из AGENTS.md имеет приоритет.

- **Чтение.** ../_система/{english-программа,слабые-места,формат-карточек}.md, ../карточки/english/, прошлые учебные заметки и непосредственно проверенный PubMed.
- **Запись.** lesson/review: личные результаты только в ../_система/{english-программа,слабые-места,журнал}.md, учебные карточки в ../карточки/english/. Для lesson допускается отдельная обезличенная заметка в content/english/ только после согласия. status работает на чтение.
- **Подтверждение и публикация.** Запуск lesson/review разрешает локальную запись прогресса при доступе на запись. Согласуй публичную заметку отдельно, затем получи подтверждение публикации после проверки. Личные ответы, исправленные фразы пользователя, ошибки и баллы остаются локально.

Прочитай `../_система/english-программа.md` (текущий модуль, последний урок) и раздел English в `../_система/слабые-места.md`. Режим: аргументы запроса.

- **status** — покажи прогресс по модулям и предложи, что дальше. На этом всё.
- **review** — только повторение: 20 терминов из прошлых уроков, в первую очередь из ошибок. Оцени и обнови слабые места.
- **lesson** (по умолчанию) — урок по текущему модулю. Урок ведётся на английском. Русский допустим только для объяснения сложной грамматики или если я прошу.
  1. Warm-up (5 мин): 8–10 терминов из прошлых уроков. Я быстро перевожу, ты отмечаешь ошибки.
  2. New vocabulary: 12–15 терминов по теме урока (EN, транскрипция, RU, пример).
  3. Reading: найди на PubMed одну реальную свежую аннотацию по теме модуля. Дай ссылку и краткий пересказ или допустимый короткий фрагмент для чтения в сессии. Перед чтением задай 3 вопроса на понимание.
  4. Retell: я пересказываю своими словами (3–5 предложений). Ты исправляешь и показываешь, как сказал бы носитель.
  5. Speaking (чередуй по урокам): в нечётный урок диалог «доктор — пациент» (сбор анамнеза, объяснение), в чётный — «конференция»: я минуту представляю кейс или слайд, ты задаёшь 3 вопроса из зала.
  6. Feedback: топ-5 ошибок в формате «моя фраза → правильная фраза → правило».
  7. Каждый 5-й урок модуля — мини-тест (15 заданий). Если результат ≥ 80%, переходим к следующему модулю.

**После урока:**
- по отдельному согласованию учебная заметка в `content/english/urok-NN.md`: лексика, типовые примеры и ссылка на аннотацию. Личные фразы и обратную связь сохрани только локально;
- карточки в `../карточки/english/urok-NN.json`;
- строка прогресса в `english-программа.md`;
- повторяющиеся ошибки в `слабые-места.md`;
- локальный журнал. Сборка и согласование публикации только для отдельной учебной заметки.
