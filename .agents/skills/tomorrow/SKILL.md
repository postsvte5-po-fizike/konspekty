# tomorrow

Аргументы: `[ДД.ММ.ГГГГ — необязательно; по умолчанию завтра]`.

Пути указаны от корня репозитория сайта. Прочитай AGENTS.md. Данные кафедры и внешние источники проверяй по прочитанным фрагментам. Общий порядок согласования и публикации из AGENTS.md имеет приоритет.

- **Чтение.** ../_система/{расписание,темы-по-неделям,шаблон-конспекта,формат-карточек}.md, ../_система/экзамен-вопросы/, ../_библиотека/, существующие страницы и колоды, официальный сайт расписания.
- **Запись.** Новые страницы в content/konspekty/ и content/lekcii/, их схемы, согласованные ответы в content/ekzamen/, целевые карточки в ../карточки/, целевые колоды в quartz/static/testy/decks.json и ../_система/журнал.md.
- **Подтверждение и публикация.** Сначала покажи проверенное расписание и план дня. Получи согласие перед записью. Существующие конспекты меняй только после отдельного подтверждения. Публикация после проверки сборки и явного согласия на точный diff.

Цель: к моему возвращению с пар все конспекты на завтра лежат на сайте.

1. Целевая дата: аргументы запроса, если указана; иначе следующий учебный день по Europe/Moscow (проверь через `date` и расписание). День без занятий пропускай. Явно заданную дату не переноси без согласия.
2. Номер и чётность недели возьми с сайта расписания (URL в `../_система/расписание.md`). При недоступности сайта используй резервный расчёт только в пределах того же семестра и после согласия на локальный снимок.
3. Загрузи расписание группы М-03-24 на целевую дату и возьми только 1 подгруппу. Проверь замены и переносы на эту дату. Проверь гостевой вход, целевой день и переносы. Если сайт или данные о заменах недоступны, покажи дату локального снимка, явно отметь неизвестные замены и дождись подтверждения использования снимка до продолжения.
4. Оставь только шесть предметов из AGENTS.md. Объединяй соседние пары одного занятия. Учти пометки * и ** и диапазон недель.
5. Для каждого занятия найди тему в `../_система/темы-по-неделям.md`. Если тему нельзя определить однозначно, не угадывай: пропусти занятие и задай вопрос в отчёте.
6. Если конспект темы уже есть, не пересоздавай его. Только проверь, что к нему есть карточки.
7. Лабораторные (лб): полный конспект строго по `../_система/шаблон-конспекта.md`. Прочитай шаблон перед работой. Материал бери из `../_библиотека/<slug>/`, сначала методичку и тематический план по теме. Лекции (лк): обзор по правилам внизу шаблона.
8. Подготовь карточки для новых конспектов по формату. Проверь JSON и обнови только целевые TXT, колоды и ссылки. Для существующих конспектов проверь наличие карточек без правок.
9. Допиши строку в `../_система/журнал.md`.
10. Собери Quartz в отдельный временный каталог. Исправляй только свои материалы, максимум две попытки. Покажи точный diff и запроси отдельное подтверждение публикации.
11. Отчёт: `✅` список конспектов со ссылками на сайт, `⚠️` проблемы, `❓` вопросы.

Ограничения: максимум 6 конспектов за запуск. Только целевая дата, не забегай на другие дни.
