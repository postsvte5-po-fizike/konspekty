# Медицинские конспекты

Выбирай навык из `.agents/skills/<команда>/SKILL.md`. Терминальные примеры: `study tomorrow`, `study note patanat 6`, `study exam patanat q 24–26`, `study case emergency`, `study surgery "Пластика ПКС"`, `study english status`, `study digest 2026-09`. В Codex доступны навыки через `/skills`. `konspekt patanat 6` и короткий запрос `patanat 6` в чате используют навык `note`. Пиши по-русски для студента 3-го курса, кроме англоязычных форматов соответствующих навыков.

- Используй локальные учебники, методички, тематические планы и экзаменационные перечни из `../_библиотека/` и `../_система/`. Объясняй нормальную физиологию, патогенез, морфологию, клинические проявления и исходы в пределах темы. Используй таблицы, условные клинические примеры и вопросы с ответами. Добавляй оригинальные схемы и английские термины по учебной необходимости.
- Читай нужные фрагменты первоисточников и фиксируй, что именно они подтверждают. Не выдумывай факты, библиографические данные, страницы и DOI. Отмечай недоступные источники, пробелы и расхождения. Явно отделяй требования кафедры от дополнительных сведений.
- Храни конспекты, экзаменационные ответы, обзоры лекций и тесты в их существующих разделах. Перед записью нового конспекта согласуй план. Изменяй существующий конспект только после отдельного подтверждения пользователя.
- Защищённые учебники, персональные материалы и клинические данные оставляй вне публичного репозитория. Для сторонней иллюстрации проверь разрешение на публикацию и соблюдай условия атрибуции.
- Шесть учебных предметов: `patanat`, `patfiz`, `topanat`, `propedevtika`, `farma`, `obshaya-hirurgiya`. Резерв для осени 2026/27: неделя 1 началась 31.08.2026. Используй его только в пределах этого семестра после подтверждения локального снимка расписания.
- Приватные источники читай на месте. Записывай личные результаты тренировок и English только в локальные файлы прогресса вне сайта, перечисленные в навыке. При отсутствии доступа запроси его для конкретной локальной записи.
- Проверяй совместимость с Quartz и выполняй локальную сборку при доступных зависимостях. Перед публикацией покажи точный diff и результат сборки, затем получи явное подтверждение. Для согласованной публикации используй существующий GitHub Pages workflow и включай только одобренные публичные изменения. Операции Git требуют соответствующего разрешения. StudyApp не входит в рабочие задачи.
